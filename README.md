# 🏍️ MotoRIDE - MVP

Plataforma digital para facilitar la solicitud de transporte en moto de mercancía y documentos. Conecta a usuarios con conductores en tiempo real (simulado).

## 🚀 Visión
Ofrecer una asignación de viajes rápida, segura y eficiente.

## 🛠️ Tecnologías
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Persistencia:** LocalStorage (Simulación de Base de Datos).
* **Arquitectura:** Modular (MVC simplificado).

## 📋 Funcionalidades (Sprint 1 & 2)
1.  **Registro y Autenticación:** Roles de Cliente y Conductor.
2.  **Solicitud de Viaje:** Creación de tickets con origen, destino y tarifa.
3.  **Gestión de Estados:** Solicitado -> Asignado -> En Camino -> Entregado.
4.  **Panel de Conductor:** Aceptar/Rechazar solicitudes.

## 📦 Instalación
1.  Clonar el repositorio: `git clone https://github.com/tu-usuario/motoride.git`
2.  Abrir `index.html` en tu navegador.
